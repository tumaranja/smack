# Smack 🖐️

Smack annoying posts out of your LinkedIn and X feeds. A hand swoops in,
**SMACK!** The post goes flying, hidden via the site's own hide
feature.

This is the public home of Smack:

- **[Privacy policy](PRIVACY.md)**: the short version is no data
  collection, no servers, nothing leaves your browser.
- **[Report a problem](https://github.com/tumaranja/smack/issues)**: if
  smacking ever stops working (usually because the site changed its
  page markup), open an issue here.

Not affiliated with or endorsed by LinkedIn or X.
